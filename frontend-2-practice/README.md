# КОНТУР — выбор даты и времени

Задание 2 по JavaScript. Календарь и выбор времени работают на нативном JavaScript поверх вёрстки из первой практики.

## Как открыть

Распакуйте архив и откройте `index.html` из папки `frontend-2-practice`. Сборка, установка пакетов и интернет не нужны.

## Что проверить

- При открытии выбран сегодняшний день по часам устройства, либо ближайший день со свободными слотами. Время выбирается отдельно.
- Стрелки листают месяцы в обе стороны. Прошедшие даты и дни соседнего месяца в сетке приглушены и недоступны для выбора.
- При выборе нового дня слоты обновляются, прежнее время сбрасывается. Нижняя панель показывает день недели, число, месяц, год и выбранное время.
- В демонстрационном расписании по пятницам всё занято. Нажмите на ближайшую доступную для выбора пятницу, затем на кнопку с предложенной датой.
- Кнопка «Далее» становится доступной после выбора времени и показывает сообщение о следующем шаге на этой же странице.

## Файлы

- `index.html` — разметка. `script.js` подключён внизу `body`.
- `styles.css` — оформление и адаптация экрана.
- `script.js` — демонстрационное расписание, состояние страницы, функции работы с датами, отрисовка и обработчики.
- `fonts/` — локальные шрифты и их лицензии.
