# КОНТУР — выбор даты и времени

Один экран по макету «04 · Дата и время» из файла `Kontur_Booking.fig`.

## Как открыть

Распакуйте архив и откройте `index.html` в браузере. HTML, CSS и шрифты лежат в папке `frontend-1-practice`. Подключение к интернету, установка пакетов и сборка не нужны.

## Что можно проверить

- При открытии выбраны 12 декабря 2026 года и 14:00, как на макете.
- Дата и свободное время переключаются с помощью обычных радиокнопок. Состояния и подписи меняются через CSS. На остальных доступных датах используется тот же демонстрационный набор слотов.
- 11 декабря показывает состояние «На этот день всё занято». Кнопка «Выбрать 12 декабря» возвращает свободные слоты. Занятые часы нельзя выбрать.
- На узком экране календарь и время располагаются друг под другом.

Демонстрация охватывает декабрь 2026 года и один шаг записи. Стрелки месяца и кнопки «Назад» и «Далее» иллюстрируют оформление элементов из макета.
